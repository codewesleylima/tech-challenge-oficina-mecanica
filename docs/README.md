# Documentation map

The root `README.md` is the human entry point. Specialist and agent-oriented guidance is
organized under `.github/agents` and `.github/skills`.

## Agent control plane

- `.github/agents/orchestrator.md`: routes work to the smallest relevant set of skills.
- `.github/agents/guardrails.md`: reviews outputs and enforces quality and safety gates.

## Academic material

University PDFs are intentionally not versioned. They are ignored by `*.pdf` in `.gitignore`.
Keep local copies under `transcricoes/` and use the versioned index:

- `docs/academic/README.md`
